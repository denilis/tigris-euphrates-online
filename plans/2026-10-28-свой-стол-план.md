**Спецификация:** `specs/2026-10-28-свой-стол-спецификация.md` (ред. 2)

## Challenge Log
**Проблема.** Сайт на Vercel: вход по личному коду, лобби, партия по правилам с проверкой каждого хода, скрытая информация, бот за столом, история для «проигравший первым», свои карты. У Vercel нет постоянного процесса, памяти между вызовами, своего диска и надёжных WebSocket.

**Выбранное решение.** Тонкий слой поверх готового движка:
- `game/` — чистая логика стола без сети, базы и npm-зависимостей (тесты идут без `npm install`);
- одна функция-маршрутизатор Vercel `api/[...route].js` читает стол из Upstash Redis, проверяет ход, пишет обратно атомарно по версии;
- клиент опрашивает версию стола раз в 1-1,5 с (одна команда Redis на опрос) и при изменении забирает свой вид;
- бота запускает опрос: ответ несёт `botDue`, клиент шлёт `bot-tick`, функция делает ход бота асинхронно, не блокируя другие запросы;
- клиент без сборки: ES-модули из `public/`, вёрстка из макета;
- паспорт карты считается в браузере (Web Workers).

**Рассмотренные альтернативы.**
1. Socket.io на постоянном сервере (Railway, Render): проще бот и рассылка. Отвергнуто: Денис выбрал Vercel.
2. Встроенные WebSocket Vercel (бета): рвутся по лимиту функции, привязаны к экземпляру, всё равно нужен Redis. Для пошаговой игры выигрыш около секунды. Отвергнуто.
3. Ably или Pusher: мгновенно, но ещё аккаунт и ключ. Отложено: подключается позже без переделки.
4. boardgame.io, Colyseus: чужая модель фаз, Colyseus требует постоянный процесс. Отвергнуто.
5. Postgres (Neon): для «документ стола + версия» Redis проще; атомарность даёт Lua. Выбран Redis.
6. Бот в браузере хоста: браузер получил бы руку бота. Отвергнуто для партий; для паспорта карты (одни боты) подходит.
7. Самовызов функции для цепочки ходов бота: на preview-деплое упирается в защиту Vercel (401), лишняя сложность. Заменено запуском от опроса клиента.

**Почему выбранное лучше.** Один внешний сервис (Redis), вся проверка правил на сервере, логика стола тестируется без Vercel и без npm. Лимиты Hobby покрывают игру компании: CPU бота по замерам 1-2 минуты на бота за партию (не 5-7, как считалось), опрос одной командой Redis даёт около 58 часов игры в месяц на бесплатных 500 тыс. команд.

**Что Денису стоит знать про закрытый счёт и мешок.** Журнал с записями «+1 красный» (оставлен по его решению) позволяет сложить чужой счёт, а число тайлов в мешке выводится из открытых данных. Закрытый счёт и мешок процентом — удобство интерфейса. По-настоящему скрыты чужие руки, чужие сбросы и состав мешка.
