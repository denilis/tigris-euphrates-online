# План: пакет правок экрана партии (03.11.2026)

Wireframe утвержден Денисом 03.11 целиком, вместе с бессрочным хранением партий. Выкладка только по его команде.

## Решения по умолчанию
- Слой «Ходы» прячет только номера, рамка и стрелка следа остаются.
- Конец партии при 2 сокровищах и меньше на обеих картах (по правилам, движок не трогаем).
- Особые сокровища: храмы с рамкой по картам BGA, торговец берет их первыми.
- Сокровища соперников скрыты при закрытом счете до конца партии; строка журнала остается.
- Лидеры у игрока двумя группами: «на поле» и «в руке».

## Заход 1. Поле и панель (клиент)
1. Слои: `public/js/layers.js` (чистые функции, тест), ползунки в шапке вместо кнопки «Метки». `renderBoard` получает `opts.layers`: owners, support, moves, monuments. В уроках все включены, ползунков нет.
2. Сокровище: белый кубик по центру храма, у особого золотой ободок.
3. След: стрелка кончается за краем клетки + 6 px; номер действия в желтом круге с темной цифрой.
4. Игроки: панель 360 px по умолчанию, крупнее шрифт и аватар, лидеры жетонами двумя группами, сокровища `?`, если сервер их не прислал.
5. Запас: монументы 3 в ряд по 80 px, здания 44 px, подписи над рядами.
6. Лобби стола: верхнее меню сайта.

## Заход 2. Сервер и правила
1. `game/view.js`: `treasures` соперников `null`, как `score`.
2. Окно конфликта у всех: не участники видят окно только для чтения.
3. Статистика: в записи итога код стола, строка «сайт ...» ссылкой на стол.
4. Хранение: законченные столы без срока, лобби и идущие 90 дней; один раз снять срок у уже законченных.
5. Особые храмы: списки `special` для обеих карт (`tigris-bot/engine/boards.js`, копия в `game/vendor`), знак на поле, текст правил.

## Заход 3. Сигналы «ваш ход»
Звук (Web Audio, без файлов): тихий «тук» на смену хода, двойной звон на свой ход. Ползунок «Звук». Заголовок вкладки, золотая рамка поля, мигающая «Сделайте ход» после выхода времени хода.

## Заход 4. Рука слева
Настройка панели «Рука: снизу / слева» в prefs (`layout-core.js`), сетка `.app` без нижней строки, рука столбиком в свободной стороне.

## Проверка каждого захода
`node --test`, локальный сервер `tigris-dev` (3017), стол с ботами, консоль чистая, скриншот.
