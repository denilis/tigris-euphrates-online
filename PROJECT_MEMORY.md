## Текущий статус
- Вид поля выбирается: опция стола `look` (`relief` по умолчанию или `cells`), кнопки «Рельеф / Клетки» в лобби рядом с выбором поля. В партии кнопка «Поле: рельеф / клетки» меняет вид только у себя, браузер помнит выбор по столу (`tigris.look.<код>`).
- Рельеф рисуется в `public/js/board.js` из бесшовных текстур ChatGPT `public/img/terrain/sand.webp` (124 КБ, плитка 640) и `water.webp` (22 КБ, плитка 420). Река в обоих видах идет по одной маске из клеток движка, поэтому совпадает с клетками точно на любой карте. Сетка на рельефе двойная: темная линия и светлая под ней.
- «Клетки» — прежний рисунок фильтрами SVG, как до 03.11.
