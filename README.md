# Тигр и Евфрат: свой стол

Онлайн-стол для своей компании на движке правил из `tigris-bot`. Вход по личному коду, сервер проверяет каждый ход, каждый видит только своё, за стол можно посадить бота.

- Спецификация: `specs/2026-10-28-свой-стол-спецификация.md`
- План по фазам: `plans/2026-10-28-свой-стол-план.md`
- Макет экрана: `specs/2026-10-28-макет-экрана-партии.html`

## Устройство

| Папка | Что там |
|---|---|
| `game/` | логика стола без сети и базы: лобби, ходы, очерёдность, вид игрока, исход войны, бот |
| `game/vendor/` | копия движка и бота из `tigris-bot` (`node tools/sync-engine.js`, руками не править) |
| `server/` | вход по кодам, хранилище (память или Upstash Redis через REST), маршруты API |
| `api/index.js` | единственная функция Vercel, все `/api/*` идут сюда |
| `public/` | клиент (статические файлы) |
| `dev/server.js` | локальный сервер: `node dev/server.js 3017`, хранилище в памяти |
| `test/` | `node --test` |

npm-зависимостей нет: `npm install` в папке Google Диска падает, а всё нужное есть в Node 20+.

## Переменные окружения на Vercel

- `SESSION_SECRET`, `CODE_PEPPER` — длинные случайные строки (подпись входа и соль кодов)
- `ADMIN_CODE` — код админа (Денис), формат `XXXX-XXXX-XXXX`
- `ADMIN_NAME` — имя админа (по умолчанию «Денис»)
- `KV_REST_API_URL`, `KV_REST_API_TOKEN` — их добавляет интеграция Upstash Redis из маркетплейса Vercel

Деплой: `vercel deploy --prod --yes --scope denis-projects-48ea0ca1` из этой папки.
