# Tigris & Euphrates — Online

Онлайн-версия настольной игры Райнера Книции «Тигр и Евфрат» для 2–4 игроков. Правила игры применяет движок: царства, конфликты, очки, сокровища, монументы и конец игры считаются автоматически, по официальному своду правил Fantasy Flight Games (стандартная сторона поля, базовая игра).

## Режимы

- **Онлайн.** Один игрок создаёт комнату и отправляет код или ссылку-приглашение, остальные входят по ним. Партию ведёт сервер: у каждого игрока своя рука и свои очки, соперники их не видят.
  - После перезагрузки страницы или обрыва связи игрок возвращается на своё место автоматически.
  - Если игрок, от которого ждут хода или решения, не в сети дольше 45 секунд, остальные могут пропустить его: ход заканчивается, в конфликте он не добавляет тайлов.
- **На одном устройстве.** Игроки передают устройство друг другу, перед каждым ходом показывается закрывающий экран. Если в конфликте решает не активный игрок, экран передачи тоже появляется. Партия сохраняется в браузере после каждого действия.
  - Режим «тренировка» убирает экран передачи — удобно, чтобы разобраться в правилах в одиночку.

## Что реализовано из правил

- Поле 16×11: 44 речные клетки и 10 стартовых храмов с сокровищами, координаты сняты с картинки поля. В мешке 143 тайла (47 храмов, 36 ферм, 30 рынков, 30 поселений). У каждого игрока династия из четырёх лидеров, две катастрофы и 6 тайлов в руке.
- Два действия за ход:
  - лидер: поставить, переместить или убрать;
  - тайл;
  - катастрофа;
  - обмен до 6 тайлов (сброшенные уходят из игры).
- Ход можно закончить раньше.
- Ограничения на размещение:
  - фермы кладутся только на реку, остальные тайлы — только на сушу;
  - лидер ставится только рядом с храмом и не может объединять царства;
  - тайл не может объединить больше двух царств.
- Очки за тайл получает лидер того же цвета, а если его нет — царь. Тайл, объединивший два царства, очков не даёт.
- **Восстания.** Сила — храмы рядом с лидером плюс храмы из руки. Первым добавляет атакующий. При ничьей побеждает защитник. Победитель получает красное очко.
- **Войны:**
  - порядок войн выбирает активный игрок;
  - атакующий определяется по часовой стрелке от активного игрока;
  - сила — сторонники в своей части царства плюс тайлы из руки;
  - проигравший теряет сторонников, кроме храмов с сокровищами и храмов рядом с другими лидерами;
  - после каждой войны царство пересчитывается, и следующая война может не начаться.
- **Катастрофы:** нельзя класть на лидера, сокровище или монумент. Лидер, у которого не осталось соседнего храма, уходит с поля.
- **Монументы:** возводятся на квадрате 2×2 из тайлов одного цвета. В конце своего хода игрок получает очки за своих лидеров цвета монумента в том же царстве.
- **Сокровища:** торговец царства, где их два или больше, забирает все, кроме одного, и сам выбирает, какие именно.
- **Конец игры:** в конце хода на поле осталось не больше двух сокровищ, или из мешка нечего добрать. Итог считается по самой слабой сфере, сокровища игрок распределяет сам. При равенстве сравниваются следующие сферы.

Не реализованы продвинутые варианты из свода правил: здания цивилизации, «чудо», продвинутая сторона поля и «английский» вариант подкрепления.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm install
npm start        # http://localhost:3000
npm test         # тесты движка и сервера
```

Переменные окружения:

| Переменная    | Назначение                                                              |
|---------------|-------------------------------------------------------------------------|
| `PORT`        | порт HTTP-сервера (по умолчанию 3000)                                   |
| `CORS_ORIGIN` | список доменов через запятую, если клиент раздаётся с другого домена    |

Деплой — на любой Node.js-хостинг (Render, Railway, Heroku — `Procfile` уже есть).

Ограничения текущей версии:

- Комнаты хранятся в памяти процесса: перезапуск сервера обрывает идущие партии.
- Поддерживается только один экземпляр сервера (без горизонтального масштабирования).
- Пустые комнаты удаляются через 30 минут после выхода последнего игрока.

## Структура

```
server.js                 HTTP + Socket.io: комнаты, места с токенами, приватные виды, пропуск отключившихся
shared/engine.js          движок правил (общий для сервера и браузера, без зависимостей)
public/index.html         страница: лобби, комната ожидания, игра
public/css/game.css       стили
public/js/app.js          клиент: онлайн-режим, игра на одном устройстве, отрисовка
public/assets/            фон лобби и подготовленные для веба картинки (≈1,3 МБ)
assets-src/               исходные фото фишек, тайлов и поля (в игру напрямую не отдаются)
tools/prepare-assets.py   сборка public/assets/game из assets-src (нужен Pillow)
test/                     node:test — сценарии по правилам, 150 случайных партий, интеграция сервера
```

Движок детерминирован и не изменяет переданное состояние: `applyAction(state, player, action)` возвращает новое состояние или ошибку. Поэтому некорректный или враждебный запрос не может испортить партию или уронить сервер.

### Протокол Socket.io

Все события подтверждаются ответом `{ ok, error? }`. Сервер отправляет каждому игроку событие `state` — `{ room, view }`, где `view` содержит только то, что этот игрок имеет право видеть.

- **Комната:**
  - `room:create { name, maxPlayers }`;
  - `room:join { code, name }`;
  - `room:rejoin { code, token }`;
  - `room:dynasty { dynasty }`;
  - `room:start`;
  - `room:leave`.
- **Партия:**
  - `game:action { type, … }` — `tile`, `leader`, `withdraw`, `catastrophe`, `swap`, `end`, `commit`, `war`, `monument`, `treasure`;
  - `game:skip`;
  - `game:rematch`.
