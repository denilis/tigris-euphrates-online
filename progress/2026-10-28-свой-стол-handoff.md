## API для клиента (server/routes.js)
Все запросы `/api/...`, сессия в заголовке `Authorization: Bearer <token>`.
- `POST activate {code}` → `{ token, user }`; `GET me`.
- `GET admin/users`, `POST admin/users {name}` → `{ user, code }`, `POST admin/users/{id}/revoke`, `POST admin/users/{id}/code` → `{ code }` (только админ).
- `POST tables` → `{ code, view }`; `GET tables` → мои столы (код, статус, места, чей ход, `next`).
- `GET tables/{code}?logFrom=N` → вид (`game/view.js`): `seats`, `me`, `isHost`, `options`, `game.{order, river, board, monuments, players, hand, discarded, bagPct, ctx, toMove, phase, legal, preview, log, logTotal, result}`.
- `GET tables/{code}/poll` → `{ version, botDue, locked }` (одна команда базы).
- `POST tables/{code} {action, ...}`: `sit {seat}`, `leave`, `hero {seat, hero}`, `options {options}`, `seatCount {n}`, `seatKind {seat, kind}`, `bot {seat, settings}`, `moveSeat {seat, to}`, `start`, `move {version, index}`, `rematch`, `close`. Ответ: новый вид. 409 `stale` — перечитать стол.
- `POST tables/{code}/bot-tick` → `{ moved, locked, botDue, version }`.
- Опрос клиента: на видимой вкладке раз в 1-1,5 с (скрытая — раз в 10 с); версия выросла — `GET tables/{code}?logFrom=<сколько уже есть>`; `botDue && !locked` — сразу `POST bot-tick`.
